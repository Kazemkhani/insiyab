# Start here: lane 3, open data and the passenger prototype (Devin)

This lane works only with public data. It never sees RTA's provided data. Its first task could change the whole project: finding out whether RTA's open daily tap files can still be downloaded, which would give the forecast many days to learn from instead of one.

## Before you start it

1. Give Devin access to the private repository `Kazemkhani/insiyab` (in Devin's settings, under the GitHub integration, add that repository).
2. Start a new Devin session on that repository and attach this zip.

## The message to paste

```
You are lane 3 of four on the repository Kazemkhani/insiyab, branch main. Read handoff/3-devin-opendata/PROMPT.md in the repository (the same file is in the attached zip) and carry it out as my instructions, in the order of its section 8. Push to main inside your own folders only, pulling with rebase before each push. Task one, opendata/ACCESS.md, is wanted within the first hour: if the data needs an account, do not create one, write the exact steps for me in coordination/lane-3.md and carry on with task two.
```

## What it may need from a person

If RTA's open data needs an account or a key, it will write `TO AMIR:` in `coordination/lane-3.md` with the steps. Registering is yours to do, in your own name.

## What is in this zip

`PROMPT.md` and a copy of the documents it points to. The repository holds the current versions: if they differ, the repository wins.
